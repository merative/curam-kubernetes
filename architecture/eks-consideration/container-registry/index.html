Container Registry #

In Amazon Elastic Container Registry you can store and distribute container images in a fully managed private registry.

Push private images to conveniently run them in the Kubernetes Service and other runtime environments. Images are checked for security issues so that you can make informed decisions about your deployments.

An alternative to Amazon Elastic Container Registry is Artifactory Container Registry, which can also be used to store and distribute container images in a fully managed private registry.
