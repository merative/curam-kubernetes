Cúram on Kubernetes Runbook

Deploying Cúram Social Program Management on Kubernetes and Red Hat OpenShift

This runbook describes how to build, configure, deploy, and operate Cúram Social Program Management on Kubernetes. It covers Minikube, Red Hat OpenShift, Azure Kubernetes Service (AKS), and Amazon Elastic Kubernetes Service (EKS).

ArchitectureHow Cúram maps onto containers, Kubernetes, and Helm, plus the reference architecture and platform-specific considerations.PrerequisitesThe software, clusters, registries, and supporting services you need in place before you deploy.Cúram applicationInstalling the Cúram software, creating the database, and building the application ready for packaging.Building Docker imagesSetting up the Docker build context and building the Liberty, batch, XML server, and utility images.Deploying with HelmPreparing and deploying the Helm charts, handling secrets, and the full configuration reference.OperationsUpdating tooling and rolling out new versions of the Cúram deployment.MonitoringCluster status, health checks, JMX statistics, MQ queue depth events, and Apache HTTP server metrics.TroubleshootingDiagnosing common problems, remote debugging, tracing, and collecting MustGather data.

New to Cúram on Kubernetes? #

Start with Cúram on Kubernetes 101 for an introduction to containerization, Kubernetes, OpenShift, and Helm, then work through the prerequisites.

If you are looking for a specific setting, the configuration reference lists every supported Helm value.
