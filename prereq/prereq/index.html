Prerequisite software

Ready to jump right in?

Please note that the preceding section provides an introduction to the architecture of Cúram on Kubernetes and to concepts you will encounter throughout the rest of the runbook. If you have already read through the Architecture section please continue. If not, it's the place to start.

Cúram was enhanced in version 7.0.10.0 to enable it to be deployed on cloud native hosting platforms.

To build and run Cúram for Kubernetes, install the following software components:

  • Base third-party software
  • Cúram software
  • Docker®, and Helm
  • Kubernetes
    • minikube
    • ChartMuseum
  • Red Hat OpenShift
    • CodeReady Containers
  • GitHub repo

In order to be hosted on Kubernetes, Cúram has been enhanced to support the following technologies:

Notes
(1) | Kubernetes releases at a 4 month cadence. When a new version is released n-2 is deprecated, and n-3 is unsupported.
(2) | Production Support introduced in 8.2. Prior to 8.2 only Dev/Test deployments are supported.
(3) | Red Hat OpenShift releases at a 4 month cadence. When a new version is released n-1 and n-2 is in Maintenance Support, and n-3 is unsupported. For more information please see Red Hat OpenShift Container Platform Life Cycle Policy.
(4) | Cúram supports Red Hat OpenShift Extended Update Support (EUS). For more information please see Red Hat OpenShift Extended Update Support (EUS) Overview.
(5) | Supported for Development and Test environments with Java 8.
(6) | Supported for Development and Test environments with Java 21.
(7) | Supported for Production environments with Java 8.
(8) | Supported for Production environments with Java 21.
(9) | Cúram only supports IBM WebSphere Liberty when containerized as Docker containers and deployed on Kubernetes or OpenShift.
(10) | WebSphere Liberty LTS lines are updated every 3 months. As such the minimum tested version is updated on a quarterly basis.
(11) | Only Linux-based containers are supported by Cúram.
(12) | IBM MQ CD 9.4.x is supported when Cúram is containerized and deployed on Red Hat OpenShift, AKS and EKS.
(13) | IBM MQ CD 9.3.x is supported when Cúram is containerized and deployed on Red Hat OpenShift only.
(14) | Only containerized deployments on supported cloud platforms are supported.
(15) | Cúram only supports Helm version 3.x.
(16) | From Helm release v3.7.0 or greater, the ChartMuseum Push plugin to be used with Cúram must be version 0.10.0 or greater.
(17) | Docker is only supported for building container images, not as a runtime engine.
(18) | For information on supported version of Java 8 please refer to 8.2.0.0 Java8 CD.
(19) | For information on supported version of Modern Java please refer to 8.2.0.0 ModernJava CD.
(20) | From Cúram 8.2.1.0, EKS is supported for Development, Test and Production with Java 21.
(21) | Ant version 1.10.15 is supported for Java8 from Cúram v8.2.1.0 onward. For Modern Java, only Ant 1.10.15 is supported from Cúram v8.2.0.0 onward.
(22) | Ant version 1.10.6 is supported only for earlier Cúram releases (up to v8.2.0.0).
